## ITB Lean 4 Formal Verification Suite

<p align="center">
  <code>f<sub>total</sub> = f<sub>pixel</sub> ∘ f<sub>traj</sub> ∘ f<sub>cobs</sub> ∘ f<sub>slot</sub> ∘ f<sub>rank</sub> &nbsp;&nbsp;⟹&nbsp;&nbsp; f<sub>total</sub><sup>−1</sup> ∘ f<sub>total</sub> = id</code>
  <br>
  <em>Geometric Bijection</em>
</p>

Machine-checked formal verification of the mathematical, combinatorial, bit-vector, and structural theorems **and** the end-to-end executable **Core ITB** (**Desynchronized Interlocked Barrier**) encryption/decryption pipeline specification of the ITB symmetric cipher construction in **Lean 4** (`leanprover/lean4:v4.35.0`).

Every theorem in this package (`239` theorems across the six `ITB/*.lean` core modules, plus `31` theorems in `Apps/ThreeToEight.lean`, totaling `270` machine-checked theorems; accompanied by `30` **Mode 3** Gauss-Posit theorems in [`ITB/Posit.lean`](ITB/Posit.lean) and `92` additional pipeline specification and Go wire-parity theorems across the three executable **Core ITB** pipeline modules [`ITB/PipelineSpec128.lean`](ITB/PipelineSpec128.lean), [`ITB/PipelineSpec256.lean`](ITB/PipelineSpec256.lean), and [`ITB/PipelineSpec512.lean`](ITB/PipelineSpec512.lean)) is verified from first principles by the Lean 4 kernel using only the standard library (`Init`), with **zero `sorry` placeholders**, **zero user-defined `axiom` declarations**, and **zero external package dependencies**.

> **Scope and experimental status.** The Lean 4 suite provides machine-checked verification of (1) all mathematical, combinatorial, bit-vector, and structural theorems in [PROOFS.md](../PROOFS.md) and [SCIENCE.md](../SCIENCE.md), and (2) the complete 5-stage **Core ITB** geometric bijection (`f_total = f_pixel ∘ f_traj ∘ f_cobs ∘ f_slot ∘ f_rank` and `f_total⁻¹ ∘ f_total = id`) with byte-exact Go reference wire parity across all three seed/primitive widths (`128`-bit `Seed128` + `SipHash-2-4-128`, `256`-bit `Seed256` + `BLAKE2b-256`, and `512`-bit `Seed512` + `BLAKE2b-512`), both **Rank Barrier** widths (`Interlock = "48"` with `factor ∈ {1, 2, 4}` and `Interlock = "168"` with `slotBytes = 7`), all shipped key sizes (`512`, `1024`, `2048` bits), all shipped nonce sizes (`128`, `256`, `512` bits), **Mode 1**, **Mode 2** (including cross-mode decryption **Mode 1** ↔ **Mode 2**), and **Mode 3** (Gauss-Posit inscribed circle floor and posit64/quire512 sub-region chord schedule), and the `1 B .. 64 MB` container sizing and payload ladder. Optional outer stream-cipher layers (`wrapper/` and `parallax/`) are standard counter-mode stream ciphers outside the **Core ITB** geometric bijection. As stated in the main [README.md](../README.md), ITB remains an experimental construction without independent external cryptanalysis, and computational security bounds remain conditional on the PRF and CSPRNG assumptions of the underlying primitives.

## Reproducing the Verification

Install [`elan`](https://github.com/leanprover/elan) (the Lean 4 toolchain manager) and run `lake build` inside `lean/`:

```sh
cd lean
lake build
```

`lake build` reads [`lean-toolchain`](lean-toolchain) (`leanprover/lean4:v4.35.0`) and checks all six core mathematical modules (`ITB`), the **Mode 3** Gauss-Posit module (`Posit`), the three executable pipeline specification modules (`PipelineSpec`), and the `Apps/ThreeToEight` KDF module (`Apps`) with zero network dependencies and zero warnings.
